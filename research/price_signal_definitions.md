# Price signal comparison: definitions fixed before evaluation

All signals use the existing weekly, next-close, historical S&P 500 engine and existing long/short, cost and CRSP missing-return handling. Baseline remains the unmodified existing `price_signal`.

* [Blitz, Huij and Martens (2011), Residual Momentum](https://repub.eur.nl/pub/22252/ResidualMomentum-2011.pdf): regress monthly excess stock returns on an intercept and Fama–French market, SMB and HML. For each month's residual, estimate coefficients using the preceding 36 complete months, then compute the current month's out-of-sample residual. Sum the 11 lagged monthly residuals excluding the latest month and divide by their sample standard deviation. This is a point-in-time implementation choice: the article specifies 36-month regressions and standardized lagged residual returns, while the rolling one-step estimation avoids using future observations to reconstruct historical residuals. A stock requires complete daily returns throughout each required month. Only factor months ending before the last completed signal month are used. WRDS historical FF data are revised series and do not provide publication vintages; the extra calendar-month lag is conservative but cannot establish actual historical publication availability or eliminate revision bias.
* [Novy-Marx (2012), Is momentum really momentum?](https://doi.org/10.1016/j.jfineco.2011.05.003): compound six monthly returns from the intermediate 12–7 formation horizon. Following the existing baseline month-end convention, use trading days after completed month-end mark −13 through mark −7 inclusive; skip recent months. Require every daily return in this interval.
* [Da, Gurun and Warachka (2014), Frog in the Pan](https://academicweb.nd.edu/~zda/Frog.pdf): compute the baseline 11-month PRET, and ID = sign(PRET) × (fraction negative daily returns − fraction positive daily returns), including zero-return days in the denominator. First sort eligible stocks into PRET quintiles, then select the ten lowest-ID stocks within the bottom quintile for the short leg and ten lowest-ID stocks within the top quintile for the long leg. Stable PERMNO ordering resolves ties. This is a double sort, without invented signal-mixing weights. If either extreme quintile has fewer than ten names, remain in cash under the existing engine rule.

The 2021–2025 evaluation and all three terminal-loss assumptions are prespecified; assumptions are not observed returns. The underlying accounting and missing-return limitations of the existing engine remain applicable.
