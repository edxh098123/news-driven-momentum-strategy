# Intermediate 12–7: 2010–2020 specification

The most recent request specifies the 2010–2020 interval. The existing `intermediate_signal`, point-in-time membership and long-only engine are used; 2009-12-31 formation executes on the first 2010 trading day. Monthly and January-phase annual schedules, one-way 10-bps execution cost, dividends, position drift and no-leverage funding are unchanged. The experiment does not reinitialize a portfolio inside the period.

The 15% volatility target is a fixed research assumption: at each scheduled formation, compute annualized standard deviation (sqrt(252)) of the prior 63 trading sessions' equal-weight daily total returns of the newly selected basket; require at least 42 days with all ten observed returns, otherwise hold cash. Exposure is min(1,0.15/estimated volatility). The estimate uses only formation-date-and-earlier information; weights then drift until the next scheduled rebalance. No borrowing; cash earns zero. This is a volatility target, not a guarantee of realized 15% volatility. Parameters are prespecified and not optimized.

This request explicitly forbids concealing missing values using zero or forward fill, so the experiment's `StrictObserved` adapter stops a path when a held security has MP price/return missing; it permits an actual observed terminal return or settlement known at that date. No assumed terminal losses are applied. The existing engine logs failed execution orders and preserves its untradeable-holding treatment; paths that cannot be valued stop independently. Any reported incomplete cumulative return is explicitly partial. Benchmark average holdings is the daily average of distinct PERMNOs in the historical membership table; it is not assumed to be exactly 500. Costs reported are the sum of daily trading-cost fractions of beginning-of-day NAV; turnover uses the same convention annualized by calendar-year length. CAGR uses calendar years; Sharpe/Sortino/alpha and volatility reuse the project's daily risk-free and annualization conventions.

The annual table permits comparison with the S&P 500's positive/negative calendar years, but the 2010–2020 period is not a strict independent validation: the strategy was selected after reviewing 2021–2025 results. Historical raw CRSP inputs remain in memory only.
